# M-academy — Digital Mathematics Academy

Школьная математическая платформа (демонстрационный прототип), RU/KZ. Сайт работает на GitHub Pages без отдельного сервера.

**Сайт:** https://gulyantsdanil-oss.github.io/m-academy/

## Текущая серверная разработка 4.1 (не развёрнута)

**Публичный сайт и серверный пилот — разные среды.** Публичный сайт GitHub Pages остаётся учебной демоверсией. В `backend/pilot-app` созданы серверные кабинеты с рабочим контуром **КТП → тема → КСП/урок → задание → результат** на основе Supabase с RLS; сервер ещё не подключён к реальным школам и не развёрнут.

- Панель сервера: `backend/pilot-app/app/overview/page.tsx`
- Связанные темы КТП: `backend/pilot-app/app/curriculum/page.tsx`
- Просмотр результатов: `backend/pilot-app/app/results/page.tsx`
- Атомарное согласование КТП и публикация заданий: `backend/supabase/migrations/`
- [Инструкция и критерии выпуска](SERVER-RELEASE-CHECKLIST.md)

**До работы с реальными школьными данными обязательны:** развёрнутые Next.js и Supabase, тестирование на фиктивных аккаунтах, проверка RLS и законности обработки данных, резервирование и приёмка. Наличие функций в репозитории **не означает** завершённого развёртывания или успешной интеграционной проверки.

## Серверный пилот: следующая архитектура (пока НЕ развёрнут)

В папке `backend/` добавлен отдельный проект серверного пилота для школ: миграции PostgreSQL/Supabase с Row Level Security, закрытыми ключами учителя, назначением ролей через доверенное администрирование, классами, КСП, заданиями, атомарной отправкой ответов и оцениванием учителем. `backend/pilot-app` — отдельное приложение Next.js, которое **не размещено на GitHub Pages**.

Что уже реализовано **в исходном коде**: вход по email для предварительно созданных аккаунтов, роли `admin/teacher/student`, список доступных классов, публикация заданий, просмотр вопросов без ключей, единовременная сдача работы и оценки педагогов. Статические контрактные проверки лежат в `backend/pilot-app/tests`.

**Новый этап:** в серверный кабинет добавлены визуальные формы КСП (этапы, действия, оценивание, ресурсы) и КТП (таблица тем и часов), безопасная предварительная загрузка отдельных материалов из JSON-резервной копии и проверка редакции документа при каждом изменении. Обновления идут через `save_teacher_material`, предотвращая потерю правок из другой вкладки. Подготовлен GitHub Actions CI для тестов SQL-контрактов, TypeScript и сборки Next.js.

**Это не готовая рабочая система:** внешний сервер и Auth ещё не настроены, код не проверен с реальной базой и не прошёл полноценный security audit. Не использовать реальные данные детей. Порядок безопасного развёртывания и ограничения указаны в [backend/README.md](backend/README.md).

## Учебный комплект

Из банка заданий можно скачать один ZIP со следующими файлами:
- `01_student.docx` — рабочий лист учащегося без ответов.
- `02_teacher.docx` — решения и ключи педагога.
- `03_ksp.docx` — сохранённый КСП либо **явно обозначенный черновик**, если КСП ещё не подготовлен.
- `04_readme.txt` — инструкция.

Word-документы создаются в браузере. Таблица КСП — альбомная A4.

## Центр учителя и Lesson Live

- **Центр учителя** индексирует уже сохранённые в браузере КТП, черновики Lesson Studio, КСП и автосохранённые черновики КСП; ничего не отправляется в GitHub.
- Резервирование в JSON содержит полный текст материалов и предназначено для **частного безопасного хранения**. Импорт предварительно проверяется и предлагает объединение без перезаписи или выборочную замену совпадающих записей. Перед заменой рекомендуется скачать текущую резервную копию.
- Недельный план хранится отдельно, локально. Он **не входит** в резервную копию учебных материалов.
- **Режим урока** получает задания из банка в текущей вкладке посредством sessionStorage, показывает их по одному и включает таймер. Это не сетевое подключение учеников.

## Работа ученика без регистрации

Учитель выбирает тему, уровень и вариант в `tasks.html`, затем нажимает «Ссылка ученику». Ученик открывает полученный `student.html?topic=...&level=...&count=...&variant=...`, вводит ответы и завершает работу; после сдачи показываются решения. Прогресс сохраняется только в браузере ученика. **Это не защищённый тест, результаты не передаются учителю автоматически.**

## Защита от потери КСП

Редактор `ksp.html` теперь сохраняет незавершённый черновик в `m-academy-ksp-autodraft-v1` и предлагает восстановление после перезагрузки страницы. Это **отдельно от ручного сохранения КСП**; резервная копия центра учителя версии `local-backup-v2` включает сохранённые КТП, уроки, КСП **и автосохранённые черновики**. Импорт старых резервных копий `local-backup-v1` поддерживается.

## Пакет для класса

В `multivariant.html` педагог создаёт от 2 до 15 вариантов, скачивает ZIP с `01_students.docx`, `02_answers.docx` и `03_info.txt`. Между вариантами предусмотрен разрыв страницы Word. Это позволяет проводить занятия без смартфонов учащихся.

## Масштабирование за пределы одной школы

Продуктовая стратегия описана в `PRODUCT-VISION.md`, а целевая защищённая архитектура — в `ARCHITECTURE.md`. Исследовательская Math Lab — первый независимый публичный учебный модуль, который может использоваться без авторизации. Использование внутри одной школы и масштабирование с аккаунтами разных учреждений — разные стадии продукта.

## Контентная библиотека 5–11 классов

- В 16 программах каталога содержится 342 тематических пункта. Все 342 ссылки ведут к индивидуальному адресу `lesson.html?course=C&topic=T`.
- Для каждого учебного адреса создана первая версия урока: теоретическое определение, правило/формула, разобранный пример, три упражнения A/B/C с ответами для самопроверки и три открытых задания на применение, сравнение и обоснование, цели урока, критерии успешности, исследовательская задача, локальный прогресс и экспорт DOCX/TXT.
- Содержание основано на **88 учебно-тематических моделях** (из них в текущем каталоге задействовано 86), поэтому многие близкие темы используют общую базовую теорию и примеры. **Это не 342 полностью самостоятельные экспертно проверенные разработки.**
- Для 14 тем доступны дополнительные генераторы числовых заданий; для остальных — тематические упражнения с раскрытием ответа, без автоматической оценки.
- Интерфейс уроков RU/KZ. Основной предметный текст теории и практики сейчас **на русском**; полная педагогическая редактура на казахском ещё не завершена.
- Формулировки целей обучения и их коды из государственных учебных программ автоматически не присваиваются, поскольку требуют сверки с действующими документами и КТП.
- Перед использованием в классе учитель должен проверить соответствие **конкретной теме**, корректность примеров, условия применения формул, правильность ответов и нормативную базу.

## Траектория изучения математики

- На страницах `lesson.html` для поддерживаемых генераторами тем можно пройти 3 числовых тренировочных задания с автоматической проверкой, в других темах — отметить **самооценку** понимания. Эти результаты **не являются итоговой оценкой по теме**.
- `mastery.js` ведёт локальные записи по идентификаторам программы и темы, различает `auto` и `self`, назначает повторение через 1, 3 или 7 дней в зависимости от результата. Состояние может изменяться при повторной попытке.
- `learning-path.html` показывает 342 темы, фильтры, рекомендации на повторение и позволяет скачать CSV со статусами. **Данные локальные; не синхронизируются между устройствами и не передаются учителю.**
- Текущий результат основан на трёх задачах или самооценке и предназначен для учебной навигации, а не для выставления школьных отметок и диагностики способностей.

## Ограничения

- **Нет реальной авторизации**, ролей и защищённого хранения данных. Кнопки входа и личные кабинеты — демоверсия; нельзя вводить настоящие пароли или персональные данные учащихся.
- КТП/уроки/КСП сохраняются локально в браузере и не синхронизируются между устройствами.
- **342 тематических пункта каталога — не 342 готовых интерактивных урока.** Автоматические задания пока генерируются только для 14 выбранных тем.
- Цели обучения и коды целей из типовой программы не назначаются автоматически: педагог должен сверить их по действующим нормативным документам.
- Экспорт и интерфейс не равнозначны финальной экспертизе математических материалов и методики.
