# M-academy 3.1 — учебный конвейер

Новая страница: **[Открыть конвейер](https://gulyantsdanil-oss.github.io/m-academy/v3-workflow.html)**.

## Возможности

- Тематический план для 5–11 классов: предмет, литера, тема, часы, дата, цель обучения, готовность.
- Демонстрационные примеры по четырём учебным классам, но без ФИО.
- Массовый CSV/TSV импорт с распознаванием разделителя, сопоставлением колонок, проверкой и предварительным просмотром.
- Исключение дублей по классу/предмету/теме/дате во время импорта.
- Переход из каждой строки КТП в конструктор КСП, Lesson Studio, каталог и банк заданий.
- Локальная очередь заданий, статусы запланировано/подготовлено/проверено.
- Сводка подготовки, CSV-выгрузка КТП/заданий, JSON-резервирование.

## Формат CSV

Заголовки шаблона: `grade;group;subject;topic;hours;goals;date`.

| Поле | Смысл | Пример |
|---|---|---|
| grade | Класс 5–11 | 9 |
| group | Литера (не обязательно) | Ж |
| subject | Математика/алгебра/геометрия | Алгебра |
| topic | Тема урока | Арифметическая прогрессия |
| hours | От 1 до 50 | 2 |
| goals | Цель / код (проверяется учителем) | |
| date | ISO 8601 или дд.мм.гггг | 2026-12-01 |

CSV можно сохранить через Excel в кодировке UTF-8. Для исходных XLSX/DOCX есть отдельный [импортер](ktp-import.html) — эта страница не пытается открыть бинарный Excel.

## Границы готовности

**Действует только локальное хранение** в браузере под ключом `macademy-v31-workflow`. Экспорт не загружает ничего в облако. Содержание не связано автоматически с прежним локальным `v3.html`, а также с `teacher-hub.html`.

Переходы открывают соответствующие существующие инструменты; они не означают автоматического переноса всей строки КТП в их хранилища. Сначала следует подтвердить корректность темы, целей, количества часов и формул.

**Это не система для настоящих детских данных.** Для защищённого многопользовательского режима требуется развёрнуть `backend/pilot-app`, настроить Supabase Auth, миграции, RLS, привязку к организации и проверку доступа. Публичный GitHub Pages не исполняет Next.js backend. См. [план интеграции](V3-INTEGRATION.md).

## Приёмочные проверки

1. Открыть `v3-workflow.html`, добавить тестовые темы и обновить страницу.
2. Скачать шаблон CSV, добавить 2–3 строки, импортировать и сверить предварительный просмотр.
3. Повторить импорт: дубликаты не должны добавиться.
4. Создать задание на основе темы, сменить статус и экспортировать CSV.
5. Скачать JSON, очистить конвейер, восстановить JSON и проверить совпадение.
6. Проверить навигацию на настольном и мобильном браузере.
7. Автопроверка `.github/workflows/v3-static-check.yml` проверяет синтаксис встроенных скриптов и локальные ссылки, но **не заменяет браузерное тестирование**.
